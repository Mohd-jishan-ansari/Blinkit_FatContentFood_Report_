# Blinkit Grocery Sales Analysis Dashboard using Power BI

## Project Overview
This project focuses on analyzing Blinkit grocery sales data using Microsoft Power BI. The dashboard provides interactive visualizations and insights into sales performance, product categories, outlet locations, outlet sizes, and customer ratings.

## Key Performance Indicators (KPIs)
- Total Sales: $82K
- Number of Items: 648
- Average Rating: 4.0
- Average Sales: $126

## Dashboard Features
- Sales Performance Analysis
- Item Type and Fat Content Analysis
- Outlet Size and Location Analysis
- Outlet Establishment Year Trends
- Outlet Type Performance Comparison
- Interactive Filters and Slicers
- Data Visualization using Charts and KPI Cards

## Tools and Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning
- Data Visualization
